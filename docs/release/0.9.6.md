# kurtz 0.9.6 Beta

Vela is now **kurtz**, always in lowercase. This release introduces the owner's
new curled wordmark and symbol, Graphite/Ivory/Electric Yellow palette and locally
bundled Sora typeface across the player, app icons, installer and product site.

[Download for Mac](https://github.com/ralleur/kurtz/releases/download/kurtz-0.9.6/kurtz-0.9.6-macOS-universal.dmg) · [SHA-256](https://github.com/ralleur/kurtz/releases/download/kurtz-0.9.6/kurtz-0.9.6-macOS-universal.dmg.sha256) · [Website](https://ralleur.github.io/kurtz/)

Version **0.9.6**, Mac build **8**. Requires **macOS 15.6+**, Apple silicon or
Intel. Quit Vela before installing kurtz. The new application is named
`kurtz.app`; remove the older `Vela.app` from Applications after confirming the
upgrade, so Finder does not offer two copies of the same player.

Accounts, local bookmarks, history and preferences keep their existing storage
identities. `kurtz://` is the primary URL scheme; `vela://` remains supported.
The old bundle identifiers are deliberately retained for upgrade compatibility.
Historical versions retain their real Vela names, tags and download filenames.

## Included

- Custom wordmark with curled z, separate curled player mark and yellow rays.
- Dark primary and light alternate icon; new tvOS tile and Top Shelf resources.
- Sora typography, new launch/about/settings identity and Jellyfin client name.
- New notarized universal Mac installer with matching artwork and volume name.
- Product site, current screenshots, social preview, six current Shorts editions,
  repository metadata and build/release tooling using the new identity.
- The completed Apple-platform work is preserved: iPhone/iPad local Files flow,
  settings, privacy manifest and platform validation tools; tvOS player controls
  retain the episode-prompt fixes. These sources are not a Store announcement.

## Verification and limits

The Mac app is Developer ID signed, notarized and stapled; strict signing and
Gatekeeper checks pass. Both arm64 and x86_64 slices are present. Runtime and
visual checks were on Apple silicon; Intel and minimum-OS runtime qualification
remain outstanding. All **46 logic tests** pass. Mac Release plus iPhone/iPad
and tvOS simulator builds pass; app identity, resources and URL schemes are
inspected in their built bundles. Mobile/TV appearance is checked in simulators.

There is no iPhone/iPad/tvOS App Store or TestFlight release in this publication.
Physical-device playback qualification, long sessions and all codec/HDR cases
are outside the evidence for this rebrand. See the [product audit](../product-audit.md).
