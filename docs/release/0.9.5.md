# Vela 0.9.5 Beta

[Download Vela for Mac](https://github.com/ralleur/Vela/releases/download/vela-0.9.5/Vela-0.9.5-macOS-universal.dmg) · [SHA-256](https://github.com/ralleur/Vela/releases/download/vela-0.9.5/Vela-0.9.5-macOS-universal.dmg.sha256) · [Project website](https://ralleur.github.io/Vela/)

Version **0.9.5**, Mac build **6**. Requires **macOS 15.6 or later** on Apple
silicon or Intel. Open the DMG and drag Vela into Applications, replacing the
previous version after quitting it. Existing accounts and preferences are kept.

## Player improvements

- Audio/subtitle quick buttons now use the Mac toolbar's button height and
  have enough width for their labels and active checkmark.
- The combination without subtitles uses a short language label, such as
  **DE**, instead of **DE ohne UT**. VoiceOver retains the full description.
- Intro and next-episode prompts remain directly clickable on Mac and can be
  activated with Return while the other controls are hidden.
- The shared release source includes the Apple TV fixes: touching the Siri
  Remote no longer reveals navigation while a skip or actionable next-episode
  button is waiting. A series-outlook card without a next episode leaves normal
  navigation available.

Local video opening, Jellyfin playback, track memory, timing controls, custom
presets, fullscreen and the floating mini player remain included. No playback
engine or dependency was upgraded for this release.

## Installer and verification

The universal app is Developer ID signed and notarized by Apple, with a stapled
ticket. The DMG retains the approved Vela installer artwork and the
drag-to-Applications layout from 0.9.4 revision 3.

The release checks cover both Mac architectures, strict code signing,
notarization, Gatekeeper and all **46 logic tests**, including the two remote
touch regression tests. Runtime verification is on Apple silicon; the Intel
slice and the oldest supported macOS version have not been runtime-qualified.
Codec/HDR combinations and long playback sessions remain beta qualification
limits. This download is a Mac release, not a new tvOS binary distribution.
